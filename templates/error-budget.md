# Error Budget Policy / Política de Error Budget

## Budget / Orçamento

**EN:** e.g. 0.1% downtime per 30 days ≈ 43 minutes.

**PT:** ex. 0.1% downtime por 30 dias ≈ 43 minutos.

## Rules / Regras

| Budget remaining | EN action | Ação PT |
|------------------|-----------|---------|
| > 50% | Normal feature velocity | Velocidade normal de features |
| 25–50% | Increase review rigor | Aumentar rigor de review |
| < 25% | Reliability focus only | Foco só em fiabilidade |
| Exhausted | Freeze risky changes | Congelar mudanças arriscadas |

## Review cadence / Cadência de revisão

Weekly / Semanal
